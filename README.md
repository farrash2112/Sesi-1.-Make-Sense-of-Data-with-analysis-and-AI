# Make Sense of Data with Analytics and AI
**Studi kasus:** toko daring ingin memahami produk penyumbang pendapatan dan mengklasifikasikan transaksi sebagai penjualan tinggi/rendah berdasarkan atribut transaksi.

**Jalankan:** `python analytics_ai.py`

Skrip membuat data sintetis, mencetak ringkasan analitik, melatih Decision Tree, menampilkan metrik, dan menyimpan grafik `ringkasan_penjualan.png`.

## Instalasi

Gunakan Python 3.10 atau lebih baru. Dari folder repository, jalankan:

```bash
python -m venv .venv
```

Aktifkan lingkungan virtual:

- Windows: `.venv\Scripts\activate`
- Linux/macOS: `source .venv/bin/activate`

Pasang dependensi:

```bash
pip install -r requirements.txt
```

## Catatan

Lihat deskripsi studi kasus di atas sebelum menjalankan program. Jika `requirements.txt` kosong, program hanya memakai pustaka bawaan Python.
